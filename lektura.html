Co robi przeglądarka, Apache i baza

Przeglądarka renderuje HTML/CSS i uruchamia JS. Apache z PHP wykonuje skrypt na serwerze, a MySQL/MariaDB zwraca dane z zapytania.

przeglądarka → Apache/PHP → baza

HTML od zera

Zbuduj poprawny dokument z nawigacją, obrazem, tabelą i formularzem, korzystając z osobnego CSS.

Szkielet dokumentu

DOCTYPE wybiera współczesny tryb renderowania. W html podaj język, a w head kodowanie, viewport, tytuł i zasoby.

<!doctype html>
<html lang="pl">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Cennik</title>
  <link rel="stylesheet" href="style.css">
  <script src="app.js" defer></script>
</head>
<body><h1>Cennik</h1></body>
</html>

Zapamiętaj. DOCTYPE jest deklaracją. title ustawia tytuł zakładki, h1 tytuł treści.

Sprawdź się. Napisz szkielet z pamięci i sprawdź polskie litery.

Semantyka układu i nagłówki

header, nav, main, section, article, aside i footer informują o roli zawartości. Poziom nagłówka odzwierciedla hierarchię.

<header><h1>Katalog</h1></header>
<main><section><h2>Oferta</h2><p>Trzy modele.</p></section></main>
<footer>Kontakt</footer>

Zapamiętaj. Sam rozmiar tekstu ustaw CSS-em.

Sprawdź się. Zamień szereg divów na czytelny układ semantyczny.

Atrybuty i elementy puste

id identyfikuje pojedynczy element. class możesz nadawać wielu elementom. data-* przechowuje dane pomocnicze. img, input, meta i link są elementami pustymi.

<img id="miniatura" class="foto" src="a.jpg" alt="Rower">
<button type="button" data-cena="14">Wybierz</button>

Zapamiętaj. Powtórzony identyfikator komplikuje JS i odnośniki.

Sprawdź się. Rozpoznaj, które atrybuty można bezpiecznie powtórzyć.

Linki i kotwice

href może prowadzić do pliku, pełnego URL albo fragmentu z id. Tekst linku powinien opisywać cel.

<a href="oferta.html">Oferta</a>
<a href="#kontakt">Kontakt</a>
<section id="kontakt"><h2>Kontakt</h2></section>

Zapamiętaj. Adres #kontakt zadziała, jeśli w dokumencie istnieje id="kontakt".

Sprawdź się. Dodaj odnośnik z podfolderu do pliku poziom wyżej.

Obraz i tekst alternatywny

src podaje ścieżkę. alt przekazuje informację potrzebną po pominięciu obrazu, a alt="" oznacza dekorację.

<figure>
  <img src="img/mapa.png" alt="Trasa od dworca do parku">
  <figcaption>Trasa A</figcaption>
</figure>

Zapamiętaj. Nazwa pliku zwykle mało mówi o treści obrazu.

Sprawdź się. Zapisz trafny alt mapy, zdjęcia produktu i ikony dekoracyjnej.

Listy i zagnieżdżanie

ol oznacza kolejność, ul wypunktowanie, li pozycję. Listę zagnieżdżoną umieszczaj wewnątrz li.

<ol><li>Importuj bazę</li><li>Wykonaj zapytania</li></ol>

Zapamiętaj. Bezpośrednio wewnątrz ul i ol dodawaj pozycje li.

Sprawdź się. Zapisz listę kroków i podlistę plików.

Tabele danych

table zawiera wiersze tr, a tr komórki th lub td. caption opisuje tabelę, a scope powiązanie nagłówka.

<table>
  <caption>Cennik</caption>
  <thead><tr><th scope="col">Usługa</th><th scope="col">Cena</th></tr></thead>
  <tbody><tr><td>Serwis</td><td>49 zł</td></tr></tbody>
</table>

Zapamiętaj. colspan łączy kolumny, rowspan wiersze.

Sprawdź się. Dodaj wiersz komunikatu obejmujący dwie kolumny.

Formularz i wysyłka

action wskazuje odbiorcę. GET przekazuje pola w adresie, POST w ciele żądania. name to klucz odebrany przez serwer.

<form action="zapis.php" method="post">
  <label for="email">E-mail</label>
  <input id="email" name="email" type="email" required>
  <button type="submit">Zapisz</button>
</form>

Zapamiętaj. for odwołuje się do id, a PHP odczytuje name. Weryfikacja w HTML wspiera użytkownika i trzeba ją powtórzyć w PHP.

Sprawdź się. Napisz formularz POST, którym PHP otrzyma klucz email.

Pola wyboru i przyciski

Radio z taką samą nazwą działa jako grupa. Checkbox może nie trafić do żądania, jeśli jest odznaczony. option value jest wartością wysyłaną.

<label><input type="radio" name="tryb" value="1"> Standard</label>
<label><input type="radio" name="tryb" value="2"> Premium</label>
<button type="button">Przelicz</button>

Zapamiętaj. Przycisk w formularzu domyślnie może wysłać formularz.

Sprawdź się. Zbuduj select z dwiema opcjami i opcjonalny checkbox.

CSS od selektorów do układu

Odtwórz dwukolumnowy układ arkusza i przypisz style tylko elementom wskazanym w poleceniu.

Zewnętrzny arkusz i selektory

Selektor typu wskazuje tag, kropka klasę, kratka identyfikator. Przecinek grupuje niezależne selektory.

p { color: #222; }
.karta { padding: 12px; }
#wynik { font-weight: 700; }
h1, h2 { margin-top: 0; }

Zapamiętaj. .karta i #karta oznaczają różne atrybuty.

Sprawdź się. Ustaw jeden kolor dla h1 i h2 bez powtarzania deklaracji.

Relacje, atrybuty i pseudoklasy

A B wybiera potomka, A > B dziecko, plus sąsiedniego brata. :hover, :focus-visible i :nth-child testują stan lub pozycję elementu.

nav > a:hover { color: #b11; }
input[type="email"]:focus-visible { outline: 2px solid navy; }
tbody tr:nth-child(even) { background: #eee; }

Zapamiętaj. tbody w selektorze pomaga zachować kolor nagłówka tabeli.

Sprawdź się. Zaznacz tylko parzyste wiersze danych.

Kaskada i dziedziczenie

Przeglądarka rozstrzyga m.in. ważność i pochodzenie reguły, specyficzność oraz kolejność. W tym samym poziomie kaskady id przebija klasę, a późniejszy remis wygrywa.

#cena { color: purple; }
.wyroznione { color: green; }
.wyroznione { color: navy; }

Zapamiętaj. Dziedziczy się m.in. color, ale margin elementu nadrzędnego nie przechodzi na dziecko.

Sprawdź się. Jaki kolor otrzyma element przy samym class i przy obu atrybutach?

Box model i jednostki

Padding jest wewnątrz obramowania, margin na zewnątrz. border-box wlicza padding i obramowanie do podanej szerokości.

.karta { box-sizing: border-box; width: 240px; padding: 12px; border: 2px solid; margin: 8px; }

Zapamiętaj. Przy content-box zewnętrzny obrys to tu 268px bez marginesów.

Sprawdź się. Policz szerokość obrysu tego elementu przy border-box.

Kolory, tło i tekst

W szesnastkowym #RRGGBB każda para koduje kanał. font-family podaje listę krojów, text-align wyrównuje treść w obszarze elementu.

body { color: #18202b; background-color: #f3f4f6; font-family: Arial, sans-serif; }
header { text-align: center; }

Zapamiętaj. color to kolor tekstu, background-color to tło.

Sprawdź się. Ustaw tło i kolor stopki bez wpływu na resztę dokumentu.

Flexbox

Rodzic z display:flex układa dzieci wzdłuż osi głównej. justify-content rozkłada je na osi głównej, align-items poprzecznie.

.panel { display: flex; gap: 16px; align-items: start; }
.lewy { flex: 2; }
.prawy { flex: 1; }

Zapamiętaj. Zmiana flex-direction zmienia osie.

Sprawdź się. Ustaw dwa panele 2:1 i sprawdź ich układ po zmianie kierunku.

Grid i breakpointy

Grid definiuje tory kolumn i wierszy. Query wybiera zestaw reguł według szerokości obszaru wyświetlania.

.karty { display: grid; grid-template-columns: 1fr 1fr; gap: 1rem; }
@media (max-width: 650px) { .karty { grid-template-columns: 1fr; } }

Zapamiętaj. Sprawdź obie strony granicy, np. 650 i 651 px.

Sprawdź się. Odtwórz proporcję 2:1 i przełącz na jedną kolumnę.

Float i pozycjonowanie

float pozwala tekstowi opływać element i pojawia się w starszych układach. clear usuwa opływanie obok poprzednich floatów. Absolute liczy położenie względem właściwego kontenera pozycjonowanego.

.foto { float: left; margin-right: 12px; }
footer { clear: both; }
.karta { position: relative; }
.etykieta { position: absolute; top: 0; right: 0; }

Zapamiętaj. Sam position:relative nie układa dzieci w kolumnach.

Sprawdź się. Pokaż podgląd po usunięciu clear w przykładzie z kolumnami float.

Tabele, obrazy i przewijanie

border-collapse scala krawędzie komórek. max-width chroni przed wystawaniem obrazu. Obiekt może zachować proporcje w prostokącie przez object-fit.

table { border-collapse: collapse; width: 100%; }
th, td { border: 1px solid #555; padding: .4rem; }
img { max-width: 100%; height: auto; }

Zapamiętaj. width i height wymuszone niezależnie mogą zdeformować obraz.

Sprawdź się. Przetestuj tabelę z bardzo długą komórką na telefonie.

SQL i bazy danych od zera

Zaimportuj bazę, napisz kwerendy z JOIN i agregacją, wykonaj kontrolowany UPDATE i udokumentuj wyniki.

Tabele, rekordy, klucze i typy

Klucz główny jednoznacznie wskazuje wiersz. Klucz obcy odwołuje się do identyfikatora w innej tabeli. W MariaDB typ DECIMAL sprawdza się dla kwot.

CREATE TABLE typy (id INT PRIMARY KEY, nazwa VARCHAR(80));
CREATE TABLE rowery (id INT PRIMARY KEY, typ_id INT, stawka DECIMAL(7,2), FOREIGN KEY (typ_id) REFERENCES typy(id));

Zapamiętaj. Typ liczbowy nie zastępuje poprawnego klucza relacji.

Sprawdź się. Rozpisz relację jeden-do-wielu dla kategorii i produktów.

Normalizacja i więzy

Wydziel powtarzalne słowniki, aby zmiana nazwy typu wymagała jednej aktualizacji. NOT NULL wymaga wartości, UNIQUE ogranicza duplikaty.

CREATE TABLE kategorie (id INT PRIMARY KEY, nazwa VARCHAR(80) NOT NULL UNIQUE);

Zapamiętaj. Id kategorii w produktach może się powtarzać.

Sprawdź się. Uzasadnij podział arkusza produktów na dwie tabele.

SELECT, alias i DISTINCT

SELECT wybiera kolumny, FROM tabelę. AS nadaje alias w wyniku. DISTINCT usuwa powtórzenia całego zestawu wybranych kolumn.

SELECT nazwa, stawka AS cena_godziny FROM rowery;
SELECT DISTINCT typ_id FROM rowery;

Zapamiętaj. SELECT * może dać kolumny, których zadanie nie wymaga.

Sprawdź się. Zwróć dokładnie dwie wskazane kolumny, w podanej kolejności.

WHERE i wzorce

WHERE wybiera pojedyncze rekordy. LIKE rozpoznaje % jako dowolny ciąg i _ jako jeden znak. IS NULL testuje brak wartości.

SELECT nazwa FROM rowery
WHERE dostepny = 1 AND (nazwa LIKE 'M%' OR nazwa LIKE 'R%');

Zapamiętaj. Grupuj AND i OR nawiasami. Kolumny z NULL sprawdzaj przez IS NULL.

Sprawdź się. Wyszukaj nazwy kończące się na „k” z pominięciem niedostępnych.

Sortowanie i LIMIT

ORDER BY wybiera kolejność, ASC rosnąco, DESC malejąco. Podaj dodatkową kolumnę przy remisach, jeśli kolejność ma znaczenie.

SELECT nazwa, stawka FROM rowery
ORDER BY stawka ASC, nazwa ASC LIMIT 3;

Zapamiętaj. Bez ORDER BY baza nie gwarantuje kolejności wyniku.

Sprawdź się. Podaj dwie najdroższe oferty. Przy remisie posortuj po nazwie.

INNER JOIN i LEFT JOIN

INNER JOIN zwraca pasujące pary. LEFT JOIN zachowuje również wiersze z lewej tabeli bez dopasowania. Warunek ON opisuje relację.

SELECT r.nazwa, t.nazwa AS typ
FROM rowery AS r INNER JOIN typy AS t ON r.typ_id = t.id;

Zapamiętaj. Warunek prawej tabeli w WHERE może usunąć niezłączone wiersze.

Sprawdź się. Wyświetl wszystkie kategorie, także puste.

COUNT, SUM, AVG, MIN, MAX

COUNT(*) liczy wiersze. COUNT(kolumna) liczy wartości różne od NULL. Pozostałe agregaty liczą sumę, średnią lub skrajne wartości.

SELECT COUNT(*) AS liczba, AVG(stawka) AS srednia
FROM rowery WHERE dostepny = 1;

Zapamiętaj. COUNT(*) po LEFT JOIN daje 1 dla zachowanej pustej grupy. Wtedy policz id po prawej.

Sprawdź się. Oblicz liczbę i najwyższą cenę dostępnych produktów.

GROUP BY i HAVING

GROUP BY scala wiersze w grupy. WHERE filtruje przed grupowaniem, HAVING po zbudowaniu grup.

SELECT typ_id, COUNT(*) AS liczba FROM rowery
WHERE dostepny = 1 GROUP BY typ_id HAVING COUNT(*) >= 2;

Zapamiętaj. W prostych kwerendach wszystkie nieagregowane wybrane kolumny dodaj do GROUP BY.

Sprawdź się. Policz modele osobno dla typów i pokaż grupy liczące ponad dwa.

INSERT, UPDATE, DELETE

INSERT dodaje rekord. UPDATE zmienia wartości, DELETE usuwa rekordy. Przed zmianą wykonaj SELECT z tym samym WHERE.

SELECT id, stawka FROM rowery WHERE id = 4;
UPDATE rowery SET stawka = 17.50 WHERE id = 4;
SELECT id, stawka FROM rowery WHERE id = 4;

Zapamiętaj. Bez WHERE UPDATE lub DELETE może objąć wszystkie wiersze.

Sprawdź się. Zmień cenę jednego rekordu i potwierdź, że pozostałe ceny nie zmieniły się.

CREATE, ALTER i widoki

CREATE TABLE zakłada strukturę. ALTER TABLE ją zmienia. Widok przechowuje definicję zapytania jako obiekt bazy.

ALTER TABLE rowery ADD COLUMN opis VARCHAR(120);
CREATE VIEW dostepne_rowery AS SELECT id, nazwa FROM rowery WHERE dostepny = 1;

Zapamiętaj. DROP usuwa obiekt, a DELETE rekordy z tabeli.

Sprawdź się. Dodaj kolumnę statusu i zbuduj widok z filtrem.

Import, eksport i uprawnienia

Wczytaj plik SQL do właściwej bazy i sprawdź tabele. W ćwiczeniowej MariaDB GRANT przydziela określone prawo na danym obiekcie.

GRANT SELECT ON inf03.rowery TO 'czytelnik'@'localhost';

Zapamiętaj. Polecenie zakłada istniejącego użytkownika. Uprawnienia ćwicz na własnej bazie.

Sprawdź się. Wykonaj eksport, odtwórz go w nowej testowej bazie i sprawdź liczbę wierszy.

Transakcje i podzapytania

Podzapytanie może zwrócić wartość do porównania. W transakcyjnej tabeli InnoDB ROLLBACK wycofuje niezapisane zmiany danych.

SELECT nazwa FROM rowery WHERE stawka > (SELECT AVG(stawka) FROM rowery);
START TRANSACTION;
UPDATE rowery SET stawka = 20 WHERE id = 4;
ROLLBACK;

Zapamiętaj. W MySQL i MariaDB wiele poleceń DDL powoduje niejawny COMMIT.

Sprawdź się. Wyszukaj ceny ponad średnią i sprawdź wycofanie aktualizacji.

JavaScript od zmiennej do interfejsu

Napisz od podstaw kalkulator lub galerię, obsłuż błędne wejście i potwierdź działanie dla wartości granicznych.

Zmienne, typy i konwersja

const wiąże nazwę bez możliwości ponownego przypisania, let dopuszcza zmianę. Pole formularza zwraca tekst.

const tekst = "12";
console.log(tekst + 5); // "125"
console.log(Number(tekst) + 5); // 17

Zapamiętaj. Number("") zwraca 0. Puste wejście sprawdź przed konwersją.

Sprawdź się. Przewidź wyniki działań z liczbą i tekstem.

Warunki i porównania

=== porównuje bez konwersji typu. && wymaga obu prawdziwych warunków. Operator reszty z dzielenia pozwala sprawdzić parzystość.

if (x >= 1 && x <= 8) { console.log("Poprawny zakres"); }
const parzysta = x % 2 === 0;

Zapamiętaj. Połączenie nierówności 1 <= x <= 8 nie działa jak zapis matematyczny.

Sprawdź się. Zapisz warunek na pełną liczbę od 1 do 8.

Pętle i wynik kodu

Rozpisz kolejne wartości licznika i zmiennej akumulującej. Indeksy tablic zaczynają się od zera.

let suma = 0;
for (let i = 0; i < 4; i++) { suma += i; }
console.log(suma); // 6

Zapamiętaj. i <= tablica.length próbuje wejść za ostatnią pozycję.

Sprawdź się. Zapisz tabelkę i, suma dla wariantu zaczynającego od 1.

Tablice i obiekty

Tablica przechowuje kolejność wartości. Obiekt pozwala nazwać właściwości. filter wybiera część tablicy, map przekształca elementy.

const rowery = [{ cena: 12, dostepny: true }, { cena: 18, dostepny: false }];
const ceny = rowery.filter(r => r.dostepny).map(r => r.cena);

Zapamiętaj. filter zwraca nową tablicę.

Sprawdź się. Wybierz dostępne modele poniżej ceny granicznej.

Funkcje i zwracanie wartości

Parametry przekazują argumenty do funkcji. return oddaje wynik i kończy wywołanie.

function koszt(cena, godziny) {
  return cena * godziny;
}
console.log(koszt(12.5, 4)); // 50

Zapamiętaj. console.log wyświetla informację, lecz nie zastępuje return.

Sprawdź się. Napisz funkcję liczącą koszt z rabatem od czterech godzin.

DOM i wybór elementu

querySelector oczekuje selektora CSS i zwraca pierwszy element albo null. getElementById oczekuje samego id.

const wynik = document.querySelector("#wynik");
wynik.textContent = "Gotowe";

Zapamiętaj. getElementById("#wynik") szuka id zawierającego kratkę.

Sprawdź się. Napraw selektor i zmień tekst w wybranym akapicie.

Zdarzenia i formularz

click reaguje na kliknięcie, input na bieżącą zmianę wartości, submit na wysyłkę. W lokalnym kalkulatorze preventDefault blokuje przeładowanie.

const form = document.querySelector("form");
form.addEventListener("submit", event => {
  event.preventDefault();
  document.querySelector("#wynik").textContent = "Obliczono";
});

Zapamiętaj. W addEventListener przekazujesz funkcję. Wywołanie z () wykona ją od razu.

Sprawdź się. Policz koszt po Enter i po kliknięciu przycisku.

Walidacja i formatowanie liczby

Sprawdź pusty tekst, poprawność liczby i granice. toFixed tworzy tekst z liczbą miejsc po przecinku. Intl.NumberFormat lokalizuje zapis.

const tekst = pole.value.trim();
const n = Number(tekst);
if (tekst !== "" && Number.isInteger(n) && n >= 1 && n <= 8) {
  wynik.textContent = new Intl.NumberFormat("pl-PL", { style: "currency", currency: "PLN" }).format(n * 12.5);
}

Zapamiętaj. parseInt("2.7", 10) daje 2, więc sam nie wykryje wpisania ułamka.

Sprawdź się. Przetestuj "", 0, 1, 8, 9 i 1.5.

Galeria, klasy i lista elementów

Zmieniaj src wraz z alt. classList.toggle steruje klasą. querySelectorAll pozwala iterować po wszystkich trafieniach.

document.querySelectorAll(".miniatura").forEach(mini => {
  mini.addEventListener("click", () => {
    duze.src = mini.src;
    duze.alt = mini.alt;
  });
});

Zapamiętaj. Dla dostępnej miniatury rozważ zagnieżdżenie obrazu w button i zdarzenie na przycisku.

Sprawdź się. Dodaj zmianę zdjęcia i tekstu alternatywnego dla trzech przycisków.

Algorytmy, obiekty i biblioteki

Przeszukiwanie liniowe sprawdza kolejne elementy. Klasa grupuje stan i zachowanie. W zadaniach pisemnych czytaj też składnię przykładów z bibliotek, np. jQuery.

const trafienie = [5, 9, 17].find(x => x > 8); // 9
class Licznik {
  stan = 0;
  dodaj() { this.stan++; }
}

Zapamiętaj. find zwraca pierwsze trafienie albo undefined, filter tablicę wszystkich trafień.

Składnia i osadzenie w HTML

PHP działa na serwerze. Zmienne zaczynają się od znaku $. Kropka łączy teksty. echo wypisuje fragment odpowiedzi.

<?php
$model = 'Rondo';
echo '<p>Model: ' . $model . '</p>';

Zapamiętaj. Ten przykład wypisuje stałą. Dla danych wejściowych koduj tekst do HTML.

Sprawdź się. Wypisz znacznik p z ceną i dopiskiem zł.

Warunki, tablice i foreach

Tablica asocjacyjna mapuje nazwy kluczy na wartości. foreach przechodzi po rekordach bez ręcznego indeksu.

<?php
$rowery = [['nazwa' => 'Most', 'cena' => 15]];
foreach ($rowery as $rower) {
    echo htmlspecialchars($rower['nazwa'], ENT_QUOTES, 'UTF-8');
}

Zapamiętaj. Tablicę asocjacyjną czytaj po kluczu użytym przy tworzeniu lub w wyniku SQL.

Sprawdź się. Policz sumę cen dla trzech rekordów.

GET, POST i walidacja

Sprawdzaj typ, brak wartości i zakres na serwerze. Opcja min_range w FILTER_VALIDATE_INT pomaga odrzucić liczbę poniżej zakresu.

<?php
$sztuki = filter_input(INPUT_POST, 'sztuki', FILTER_VALIDATE_INT, ['options' => ['min_range' => 1, 'max_range' => 8]]);
if ($sztuki === false || $sztuki === null) { echo 'Podaj od 1 do 8 sztuk.'; }

Zapamiętaj. false oznacza niepoprawną wartość, null brak wejścia.

Sprawdź się. Sprawdź reakcję PHP na pustą wartość i liczbę 9.

Dane na wyjściu HTML

htmlspecialchars koduje znaki specjalne dla kontekstu HTML. Przy dynamicznej treści i atrybutach tekstowych stosuj kodowanie przed wypisaniem.

<?php
$tekst = 'Naprawa & serwis';
echo '<p>' . htmlspecialchars($tekst, ENT_QUOTES | ENT_SUBSTITUTE, 'UTF-8') . '</p>';

Zapamiętaj. Kodowanie HTML nie zastępuje parametrów SQL.

Sprawdź się. Przewidź HTML źródłowy wyprodukowany dla nazwy „A & B”.

Połączenie mysqli i SELECT

Podaj host, konto, hasło i bazę. Ustaw utf8mb4. query wykona stałe zapytanie, a fetch_assoc pobierze wiersz według nazw kolumn.

<?php
$db = new mysqli('localhost', 'uczen', 'haslo_lokalne', 'inf03');
$db->set_charset('utf8mb4');
$wynik = $db->query('SELECT nazwa FROM rowery ORDER BY nazwa');
while ($r = $wynik->fetch_assoc()) {
    echo '<li>' . htmlspecialchars($r['nazwa'], ENT_QUOTES, 'UTF-8') . '</li>';
}
$db->close();

Zapamiętaj. Dane logowania dopasuj do ćwiczeniowego środowiska. Kod listy opakuj w ul.

Sprawdź się. Przerób pętlę na wiersze tabeli.

Parametry zapytań i zapis

prepare oddziela konstrukcję zapytania od wartości. bind_param przyjmuje typy m.in. i dla int i s dla string. Nazwy tabel są częścią ustalonej składni.

<?php
$stmt = $db->prepare('UPDATE rowery SET nazwa = ? WHERE id = ?');
$stmt->bind_param('si', $nazwa, $id);
$stmt->execute();

Zapamiętaj. Zwaliduj id i treść przed wykonaniem. Parametry nie służą do podstawiania nazw kolumn.

Sprawdź się. Napisz INSERT z dwiema wartościami podanymi jako parametry.

Wynik pusty i format danych

Podaj czytelny komunikat dla braku wyników. number_format pozwala wyświetlić kwotę z polskim separatorem dziesiętnym.

<?php
if ($wynik->num_rows === 0) { echo '<p>Brak danych.</p>'; }
echo number_format(12.5, 2, ',', ' ') . ' zł';

Zapamiętaj. Wartość wyświetlana jako „12,50 zł” nie nadaje się jako surowy operand JS.

Sprawdź się. Wyświetl kwotę w td, a surową wartość liczbową w data-cena.

Systemy liczbowe i jednostki

Cyfry w systemie pozycyjnym mnoży się przez kolejne potęgi podstawy. Bajt ma osiem bitów. KiB to 1024 bajty.

1011₂ = 1×8 + 0×4 + 1×2 + 1×1 = 11₁₀
FF₁₆ = 15×16 + 15 = 255₁₀

Zapamiętaj. Mb/s opisuje megabity na sekundę, MB to megabajty.

Sprawdź się. Przelicz 101010₂ na dziesiętny i szesnastkowy.

Kodowanie, sprzęt i systemy

UTF-8 zapisuje znaki Unicode za pomocą od jednego do czterech bajtów. RAM to pamięć robocza, SSD przechowuje dane po odłączeniu zasilania.

ę → znak Unicode → bajty UTF-8

Sieć i HTTP

GET /style.css → 200 OK

Zapamiętaj. Błędy 4xx zgłasza się w związku z żądaniem, a 5xx w związku z obsługą po stronie serwera.

Sprawdź się. Odróżnij problem z adresem zasobu od problemu uruchomienia PHP.

Fiszki
Co umieszczasz w head na początku dokumentu?

Kodowanie UTF-8, metadane viewportu, title i odwołania do zasobów. Doctype jest przed html.

Co łączy label z polem, a co tworzy klucz wysłany do PHP?

for odpowiada wartości id. Kluczem otrzymanym przez PHP jest name.

Jak połączyć „Oferta” z sekcją na tej samej stronie?

Wstaw href="#oferta" w a oraz id="oferta" w sekcji.

Kiedy użyć pustego tekstu alternatywnego?

Dla obrazu dekoracyjnego ustaw alt="" bez spacji. Dla informacyjnego opisz informacje widoczne na obrazie.

Jak odróżnić nagłówek tabeli od komórki danych?

th to nagłówek, td to wartość danych. scope wskazuje kolumnę lub wiersz.

Jaki type dla przycisku obsługiwanego wyłącznie przez JS?

type="button". W formularzu przycisk wysyłający ma type="submit".

Jak podłączyć CSS i zewnętrzny JS?

link rel="stylesheet" href="style.css" oraz script src="app.js" defer z zamknięciem script.

Jak wybrać tylko bezpośrednie linki nav?

Selektorem nav > a. Selektor nav a wybiera też zagnieżdżone linki.

Jak zaznaczyć parzyste wiersze danych tabeli?

tbody tr:nth-child(even).

Co wlicza się do width przy box-sizing: border-box?

Treść, padding i border. Margin pozostaje poza tym obrysem.

Co wygra w tej samej warstwie kaskady, #wynik czy .wynik?

#wynik ma większą specyficzność. Kolejność rozstrzyga remis specyficzności.

Czym ustawić odstępy w Flexbox lub Grid?

gap ustawia odstęp między elementami lub torami.

Jak ułożyć proporcję 2:1 w Grid?

grid-template-columns: 2fr 1fr przy display: grid.

Jak przełączyć układ przy 700 px włącznie?

@media (max-width: 700px) { ... }.

Jaka jest podstawowa kolejność klauzul?

SELECT, FROM z JOIN i ON, WHERE, GROUP BY, HAVING, ORDER BY, LIMIT.

Co umieścić w ON dla tabeli rowery i typy?

r.typ_id = t.id, jeśli typ_id jest kluczem obcym wskazującym id typu.

Jak zachować grupę bez pasującego wiersza?

Rozpocznij od tabeli grup i użyj LEFT JOIN. Warunki dotyczące dopasowania prawych rekordów umieść w ON.

Jak policzyć dopasowania po LEFT JOIN?

COUNT(p.id) liczy tylko niepuste wartości po stronie dopasowanych pozycji.

Która klauzula filtruje po liczbie elementów grupy?

HAVING, np. HAVING COUNT(*) >= 2. WHERE filtruje przed grupowaniem.

Jak znaleźć brak wartości?

IS NULL albo IS NOT NULL.

Co zrobić przed UPDATE konkretnego rekordu?

Uruchom kontrolny SELECT z tym samym WHERE. Potwierdź, że wskazuje zamierzony rekord.

Jak uruchomić odczyt od najwyższej ceny z remisem po nazwie?

ORDER BY cena DESC, nazwa ASC.

Co daje "12" + 5 i jak otrzymać 17?

Daje "125". Użyj Number("12") + 5.

Czemu sprawdzić pusty tekst przed Number?

Number("") zwraca 0, więc brak wartości może zostać pomylony z poprawnym zerem.

O co pytasz Number.isInteger(n)?

Czy n ma typ number i reprezentuje skończoną liczbę całkowitą.

Jak brzmi ostatni poprawny indeks tablicy?

tablica.length - 1, jeśli tablica ma elementy.

Co dają filter i map?

filter wybiera elementy, a map zwraca przekształconą wartość dla każdego wejściowego elementu.

Jak wstawić wynik jako zwykły tekst?

element.textContent = wynik.

Jak podpiąć funkcję bez jej natychmiastowego wywołania?

element.addEventListener("click", funkcja).

Kiedy użyć preventDefault?

Np. przy lokalnym przeliczaniu na submit, gdy formularz ma pozostać na tej samej stronie.

W którym miejscu działa kod PHP?

Na serwerze z interpreterem PHP. Przeglądarka otrzymuje wynik, zwykle HTML.

Jaką operacją łączysz dwa teksty?

Kropką, np. $nazwa . " zł".

Jak odczytać nazwę wysłaną metodą POST?

Z $_POST['nazwa'] lub filter_input(INPUT_POST, 'nazwa', ...), zgodnie z name kontrolki.

Co wywołać po otwarciu połączenia mysqli?

set_charset('utf8mb4'), aby ustawić kodowanie połączenia.

Co robi fetch_assoc()?

Pobiera kolejny rekord jako tablicę asocjacyjną, której klucze to nazwy kolumn lub aliasy.

Jak przekazać wartość wpisaną przez użytkownika do SQL?

prepare z ?, bind_param z typem i zmienną, a następnie execute.

Jak wypisać wartość tekstową wewnątrz HTML?

htmlspecialchars($tekst, ENT_QUOTES | ENT_SUBSTITUTE, 'UTF-8').

Co różni kadrowanie od skalowania?

Kadrowanie wybiera wycinek obrazu. Skalowanie zmienia jego wymiary w pikselach.

Którego formatu użyć do ikony rastrowej z przezroczystością?

PNG z kanałem alfa, jeśli taki format przewiduje zadanie.

Czy zmiana rozszerzenia .jpg na .png zmienia format?

Trzeba otworzyć plik i wyeksportować go jako PNG.

Co zapisać zaraz po wykonaniu kwerendy?

Wklej kwerendę do wymaganego pliku. Zachowaj zrzut wyniku zgodny z nazwą i formatem z polecenia.

Jaki ma być ostatni test całego zadania?

Otwórz gotowe pliki w docelowym środowisku. Sprawdź ekran, zdarzenia, dane i dokładne nazwy oddawanych plików.
