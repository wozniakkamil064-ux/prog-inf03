# PRÓG / Kurs INF.03

Interaktywny kurs do egzaminu zawodowego. Przeglądaj ścieżkę od zera, ćwicz kod, powtarzaj fiszki lub uruchom próbny egzamin. Postęp zapisuje się w używanej przeglądarce.

## Uruchomienie

Na komputerze podaj katalog plików przez dowolny statyczny serwer HTTP, np. poleceniem: python -m http.server 8767. Otwórz http://localhost:8767.

Quiz, ćwiczenia HTML, CSS, JavaScript i bazę ćwiczeniową SQLite uruchamia przeglądarka. Zadania PHP oraz próby wymagające MariaDB/MySQL wykonaj na lokalnym serwerze. Plik lektura.html daje dostęp do materiałów bez JavaScriptu.

## Wdrożenie

Repozytorium jest gotowe do publikacji przez GitHub Pages z gałęzi main i katalogu głównego.

Zadania SQL korzystają z sql.js. Licencja znajduje się w pliku LICENSE-sql.js.txt.
